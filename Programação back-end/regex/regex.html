Validação com Expressões Regulares

Atividade prática – Formulários HTML + JavaScript + Regex

1. Validação de Nome

Permite apenas letras (incluindo acentos) e espaços. Números ou símbolos tornam o nome inválido.

Exemplos:
Maria Silva → Nome válido
Maria123 → Nome inválido
João! → Nome inválido

2. Validação de Idade

Aceita somente números inteiros. Qualquer letra ou símbolo torna a idade inválida.

Exemplos:
18 → Idade válida
18 anos → Idade inválida

3. Validação de Senha

A senha deve ter pelo menos 8 caracteres, uma letra maiúscula, uma minúscula e um número.

Exemplos:
Abc12345 → Senha válida
abc12345 → Falta letra maiúscula
ABC12345 → Falta letra minúscula
Abcdefgh → Falta número

4. Validação de CEP

Aceita apenas os formatos: 99999-999 ou 99999999.

Exemplos válidos: 99999-999 ou 99999999

5. Validação de Telefone

Aceita os formatos: (45) 99999-9999 | 45999999999 | 45 99999-9999

Formatos aceitos:
(45) 99999-9999
45999999999
45 99999-9999

6. Validação de CPF (formato)

Aceita somente: 123.456.789-00 ou 12345678900. Não verifica se o CPF existe de verdade.

Formatos aceitos: 123.456.789-00 ou 12345678900

7. Extrair Números da Frase

Digite qualquer frase. O programa mostra todos os números encontrados.

Exemplo: "Hoje comprei 3 maçãs e 12 bananas." → 3 e 12

8. Contar Vogais

Conta quantas vogais (incluindo acentuadas) existem na frase digitada.

Exemplo: Programação → Quantidade de vogais: 5

9. Contar Palavras

Conta quantas palavras existem no texto usando Expressões Regulares.

Exemplo: "Hoje está um lindo dia." → Quantidade de palavras: 5

10. Página de Cadastro Completo

Todos os campos são validados com Regex. O cadastro só é concluído se tudo estiver correto. Campos inválidos ficam em vermelho.

11. Analisador de Texto

Digite qualquer frase e o sistema informa: letras, números, palavras, vogais, espaços e caracteres especiais.
